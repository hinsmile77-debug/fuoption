##### ★ P0-2 — 같은 봉을 다른 시간대로 돌려주는 로더가 둘이었다

```
ParquetArchiver.load_recent_bars_by_source() -> 2026-08-14 08:30:00+09:00 (KST)
ParquetBarReplaySource.load()                -> 2026-08-13 23:30:00+00:00 (UTC)
```

같은 순간이지만 `.hour`는 8과 23이다. `meta_labeler._minutes_since_session_open()`이
인자 이름(`bar_open_kst`)에 기대어 `.hour`를 그대로 읽어 **재생 경로에서 이 Feature가
540분 어긋났다.** 학습이 본 범위(KST −15~390)와 재생 추론이 본 범위(−540~−150)가
**겹치지도 않는다.** 값이 NaN이 아니라 그럴듯한 숫자라 아무 흔적도 없었다(금지계명 6).

**생산 경로는 무사하다** — `bar_composer.py:171`이 `.astimezone(KST)`를 명시하고 학습
경로도 KST다. 오염된 것은 `run_replay`·`run_backtest_harness`·`run_full_path_smoke`
계열, **즉 금지계명 2가 요구하는 바로 그 검증 경로**다. G1은 ParquetArchiver를 쓰므로
무관하다. 수정: `to_kst()` 경유(naive는 R3대로 거부).

영향 크기: 08-14 재생 meta 통과확률 최대 **0.2017 → 0.6576**.

## 4. D-day Go/No-Go — "모의투자 1일차 성립" 판정 기준

| # | 기준 | 성립 조건 |
|---|---|---|
| ① | **시스템 무중단** | 재기동 0 · ERROR 0 · 종료 시퀀스 정상 (기존에도 충족하던 축) |
| ② | **국면 판정 가동** | UNKNOWN 비율 **< 100%** — 하루 중 실제 국면 판정이 등장 |
| ③ | **전문가 기여** | `n_experts ≥ 1` **또는** 0의 사유가 여섯 갈래 중 하나로 **로그에 확정** |
| ④ | **판단 사슬 관통** | `decision_funnel`에 `regime` **이외의** 게이트가 최소 1회 등장 = Risk·Sizer·OrderGateway가 처음으로 라이브 입력을 받음 |

**①~③ 충족이면 1일차 성립. ④까지면 이상적.**

**거래 0건이어도 게이트가 정당한 사유(예: meta 임계 미달)로 막은 것이면 성립이다** —
못 미더운 0과 측정된 0을 가르는 것이 이 저장소의 규율이다(L18).

**리허설 기준 ①~③은 충족, ④는 안 날 가능성이 높다**(meta 최대 0.658 < 임계 0.700).
그것은 정당한 차단이지 결함이 아니며, **임계를 낮춰서 ④를 만들지 않는다**(R18) —
G1 관문을 통과한 적 없는 모델로 거래를 내는 일이 된다.

## 6. 이 계획이 틀릴 수 있는 지점

- ~~**F-1이 라이브에서 안 들을 수 있다.**~~ → **실제로 안 듣고 있었다**(§3-1-1 P0-1).
  D-2 리허설이 이 위험을 흡수하도록 설계했고, 정확히 그 일이 일어났다. 이제 남은 위험은
  "수정본이 라이브에서도 같은 답을 내는가"이고, 그것이 W-16의 채점 내용이다.
- **리허설과 라이브가 갈릴 수 있다.** 리허설은 아카이브 재생이고 라이브는 WS 틱이다.
  갈리면 그 자체가 P0이며, 예보를 §3-3에 미리 적어둔 이유가 그것이다.
- **국면이 UNKNOWN을 벗어나도 `n_experts=0`이 남는다** — 리허설이 이미 확인했다
  (`blocked_by_meta` 15/15). 둘은 독립 갈래다.
- **④까지 가면 다음 미검증 구간이 열린다** — Risk·Sizer·OrderGateway는 라이브 입력을
  받아본 적이 없다. 첫 통과 시 새로운 결함이 드러날 가능성이 높고, 그것이 수확이다.
- **이어붙인 봉의 롤 점프는 보정되지 않는다.** 08-14 경계 점프 1990틱(같은 창의 일자
  경계 갭 13건은 중앙 817 · 최대 3160틱이라 범위 안), 과거 7개 롤의 basis 중앙 116 ·
  최대 240틱만큼이 인공물이다. 이번 롤은 겹침이 없어 **측정조차 못 했다**
  (`matched_minute=None`). 구조 해법은 G-1이고 D-day 전에 하지 않는다.
- **두 parquet 로더의 시간대 불일치는 함수 하나만 고쳤다.** `ParquetBarReplaySource`가
  UTC를 돌려주는 것은 그대로다 — 다른 소비처가 같은 함정을 밟을 수 있다. G-7 계열로 이관.

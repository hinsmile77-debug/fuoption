## 작성 시 주의

- **인용 없는 이상점은 쓰지 않는다.** 로그 시각과 파일명이 반드시 붙는다.
- **"개선한다"류 동사를 쓰지 않는다.** 어느 파일 어느 함수에서 무엇을 어떻게 바꾸는지 쓴다.
- **재발 항목은 무조건 P0 맨 위로.** 원래 고쳤다는 커밋 sha까지 찾아 붙인다.
- **판정 보류를 부끄러워하지 않는다.** 틀린 확정보다 정직한 보류가 낫다. 단, 무엇을 보면 판정되는지는 반드시 쓴다.
- **전일 보고서가 있으면 델타를 쓴다.** `logs/dailycheck/` 에서 직전 것을 찾아 비교한다.
